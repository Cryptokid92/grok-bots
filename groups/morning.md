# morning

Morning desk. Sits above the day, not on send. @desk collects open loops. @brief ranks the one meeting, the one reply, and the one fire. @inbox drafts mail that cannot wait. @notes turn yesterday's call into owners. @ledger flags expense holes. @subs names cancel-or-keep. Never send, book, pay, or cancel.

## Roster

| Bot | Job in this group |
| --- | --- |
| desk | Front door. Rank leftover loops and name an owner. |
| brief | Calendar, mail, and chat into one ranked brief. |
| inbox | Reply-now, wait, archive. Drafts only. |
| notes | Decisions, owners, due dates from the last meeting. |
| ledger | Receipts vs the card export. Chase drafts. |
| subs | Recurring charges. Cancel-or-keep with evidence. |

## Handoff

1. @desk lists open loops from the sources you name.
2. @brief ranks today against that list.
3. @inbox and @notes fill the mail and meeting holes in parallel.
4. @ledger and @subs run only if you asked for money this morning, or on the weekday you set.
5. You send, book, pay, or cancel. Nobody else does.

## Kickoff

```text
Sources: calendar, overnight mail, Slack mentions.

@desk collect open loops and name an owner for each.
@brief rank today. Name the meeting that needs prep, the reply due before noon, and the thread that becomes a fire.
@inbox draft the replies that cannot wait. Do not send.
@notes if there was a meeting yesterday, return decisions, owners, and due dates. Do not invent an owner.
@ledger only if I attached a card export. Draft the chase. Do not pay.
@subs scan mail for recurring charges. Return cancel-or-keep. Do not cancel.
```

## Hard stop

Never send mail. Never book. Never pay. Never cancel a subscription.
